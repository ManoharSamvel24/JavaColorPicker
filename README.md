# JavaColorPicker
A GUI color picker Java application inpired from the power toys . A modern desktop color picker for Java inspired by PowerToys Color Picker.  
Easily pick and convert colors, with support for multiple color formats (HEX, HSL, HSV, CMYK) and clipboard copy. Developed this project in 2 weeks . It has great user friendly UI . Hope you like it

---

## ✨ Features

- 🎨 **Color Selection:** Sliders for Red, Green, Blue, and Alpha values.
- 👁️ **Live Preview:** Rounded panel shows your selected color instantly.
- 🖱️ **Screen Color Picker:** Press & drag to pick any color from your screen using a dropper tool.
- 📦 **Color Formats:** View and copy color values in HEX, HSL, HSV, and CMYK.
- 📝 **Copy to Clipboard:** One-click copy for any format—ready for use in design/code.
- 🎛️ **Modern UI:** Beautiful, FlatLaf-based look with intuitive layout.
- ℹ️ **Info Button:** About dialog and shortcuts for quick app info.

## 💡 How to Use

1. **Adjust Sliders** to set color values.
2. **See Color Preview** instantly update.
3. **Pick a Screen Color:** Click “Press & Drag to Pick Color” and drag the dropper anywhere.
4. **Choose Color Dialog:** Click “Choose Color” to select using a color dialog.
5. **Copy Format:** Click “Copy” next to any format to send it to your clipboard.
